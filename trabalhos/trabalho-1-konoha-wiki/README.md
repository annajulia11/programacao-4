# Trabalho 1 — Konoha Wiki

Wiki estática sobre Naruto Shippuden: as cinco grandes aldeias, personagens, tipos de jutsu, Akatsuki, Bijuu e a cronologia da série. Feita com HTML, CSS e JavaScript puro.

A continuação deste trabalho, com back-end e banco de dados, está em [`trabalho-2-konoha-wiki-api`](../trabalho-2-konoha-wiki-api/).

**Para abrir:** `index.html` no navegador.
