# Programação IV

Atividades, trabalhos e projetos da disciplina de **Programação IV** do curso de Ciência da Computação.

O repositório vai do front-end básico (HTML, CSS e JavaScript) até APIs REST com Node.js/Express e NestJS, banco de dados e autenticação JWT.

## Estrutura

```
programacao-4/
├── aulas/                         # Exercícios feitos em sala
│   ├── aula-02-site-winx/         # Primeiro site: fã-clube das Winx (HTML + CSS)
│   ├── aula-03-hello-kitty/       # Página da Hello Kitty & amigos (HTML + CSS)
│   └── aula-04-jogo-yami-mask/    # Jogo de clicar contra o tempo (JavaScript + DOM)
├── trabalhos/                     # Trabalhos avaliativos
│   ├── trabalho-1-konoha-wiki/    # Wiki estática de Naruto Shippuden
│   └── trabalho-2-konoha-wiki-api/# A mesma wiki, agora com API REST, SQLite e JWT
├── api-pessoa-nestjs/             # API de Pessoas em NestJS, versão por versão
│   ├── v0-estrutura-inicial/
│   ├── v1.0-crud-basico/
│   ├── v1.1-dto-e-entidade/
│   ├── v1.1b-com-testes/
│   └── v1.2-mysql-e-jwt/
└── extras/
    └── pokedex-pokeapi/           # Pokédex consumindo a PokeAPI com fetch
```

## Como abrir

- **Sites estáticos** (aulas, Trabalho 1, Pokédex): abra o `index.html` no navegador ou use a extensão Live Server do VS Code.
- **Trabalho 2**: veja o [README do trabalho](trabalhos/trabalho-2-konoha-wiki-api/README.md).
- **API NestJS**: veja o [README da API](api-pessoa-nestjs/README.md).

## Tecnologias

HTML · CSS · JavaScript · Node.js · Express · NestJS · TypeScript · TypeORM · MySQL · SQLite · JWT · Jest
